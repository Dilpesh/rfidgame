# Feedback — moved

Feedback is now one file per story, under `feedback/`, so items stop getting
mixed up between stories and the common lessons have somewhere permanent to
live.

- **`STORY_CRAFT.md`** — the writing rules, learned from all the stories.
  Run a finished script through §6 before recording anything.
- **`feedback/`** — one file per story. Start at `feedback/README.md`.

Anything that turns out to be true of every story gets promoted from a story
file into `STORY_CRAFT.md`.
