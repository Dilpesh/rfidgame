Bobo की Birthday Party — Phone NFC mode (proposal, 3 Oct 2026)

Why: on the phone, tapping a card showed Android's own "Scan result / Empty tag" screen — Bobo never asked Chrome to listen for NFC. On the laptop it works because the USB reader types the card number.

What changes: one added line in index.html and a new nfc.js (a copy of Night Drive's, plus serial conversion). The shared engine and every other game are untouched.

The conversion: Chrome reports the Speaker card as c2:23:db:30; the laptop reader types those 4 bytes reversed as a 10-digit number: 30 DB 23 C2 → 0819667906 (you confirmed this). So all five Bobo cards already in cards.json work on the phone with no teaching.
