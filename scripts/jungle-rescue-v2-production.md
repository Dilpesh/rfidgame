## Repeated on purpose

These must sound **identical every time** — same pitch, same rhythm — so the
children can join in. Repetition was the strongest device in either story.

- **The rally:** `जंगल बचाओ टीम… तैयार?!` — leave a real beat of silence after it
- **The mess cry:** `गंदा! गंदा! बहुत गंदा!` — used exactly three times
- **Every acknowledgement:** `YES! <CARD>! शाबाश किशु मिशु!` + what changed
- **Every card ask rhymes** — two beats, sing-song

## Levelling — do this to every file before it goes in

```
# narration
ffmpeg -i in.mp3 -af "loudnorm=I=-16:TP=-1.5:LRA=7" -c:a libmp3lame -q:a 2 out.mp3

# sound effects: -20 dB mean, peaks under -1.5 dBTP
ffmpeg -i in.mp3 -af volumedetect -f null -          # read mean_volume
ffmpeg -i in.mp3 -af "volume=<-20 minus mean>dB,alimiter=limit=0.85:level=false" \
       -c:a libmp3lame -q:a 2 out.mp3
```

`alimiter` **must** carry `level=false` — without it, it auto-levels to its
own ceiling and silently undoes the gain staging.

Then listen on a phone, speaker only, from two metres. A phone speaker
produces almost nothing below 450 Hz.
